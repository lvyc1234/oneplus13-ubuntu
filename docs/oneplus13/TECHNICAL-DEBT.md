# 限制与待完成项

当前持久化桌面基线的验收范围见 [STATUS](STATUS.md)。以下范围需要后续工作。

- 支持范围集中于 PJZ110、24 GB / 1 TB。其他内存布局、存储容量及固件版本需要独立设备树和安装几何验证。
- 深度挂起被屏蔽，电源键使用锁屏与显示关闭。待完成可靠的 suspend/resume 和长期续航测量。
- GPU 采用全量重绘修复旋转时的 damage clip 问题。待修复 Mutter / DRM 局部重绘路径并评估能耗。
- SSC 加速度计支持自动旋转，当前固件没有提供可用的默认陀螺仪 UID。传感器参考数据含经审查的校准，其他手机需使用自身校准验证。
- 摄像头、GNSS 定位、NFC 标签、视频硬件编解码、移动数据和通话保留实验性源码及探测工具，需要单独端到端验收。
- 音频、蓝牙、OTG 的早期阶段有独立测试记录，持久化版本尚无覆盖全部使用场景的最终验收。
- 接电关机使用最小充电 target。其能耗、温控与长时间充电仍需测量，bootloader 需要开启 off-mode-charge。
- Android OTA 可能覆盖 B 槽位或改变 Boot Control HAL。升级前需保存恢复资料，升级后重新核对 B 镜像及模块身份。
- 稳定 MAC 保持网络身份，DHCP 租约由路由器决定。固定 IP 需在路由器做地址保留。
- 全新安装和 Ubuntu 重装工具已整理为可审查的构建入口。现有安装的硬件验收不能替代新的安装器在实机上的验收。

保留每个产物的源码提交、SHA256SUMS 和设备验收结果。发布新版本时按安装、首次设置、双向切换、显示、Wi-Fi、旋转、充电、电源键和关机逐项检查。
